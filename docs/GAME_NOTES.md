Notes from the first finished GAME modules (disk.c, talk.c and the OSI assembly are identical now):
1. secmp needs --include SRC to find se.h (secheck adds it itself).
2. Put address comments (/*C_SSSS_OOOO*/, /*XXXX*/) only before DEFINITIONS, never before extern declarations: sesym now ignores them on externs, but keep the sources clean.
3. With -p every function is pascal; declare externs plainly and mark only the cdecl ones cdecl (CON_printf = C_05D0_2DB9(char far *fmt, ...) is cdecl; MOUSE_SERVE C_2ABF_00A7 cdecl, no args). sesym now treats functions in -p files as pascal unless declared cdecl.
4. A parameter declared register gets DI and a register local SI, even when the parameter is declared first (seen twice).
5. Far data outside DGROUP (segments 2F43, 2F65): declare as `extern char far C_SSSS_OOOO[];` (secmp checks C_ names there; D_ names are taken as DS offsets).
6. `!uchar` gives mov al/mov ah,0/or ax,ax; `uchar == 0` gives cmp byte,0. TC++ reuses a register after a store with no source trick.
7. sedis.py's second argument is an end PARAGRAPH, not an offset (sedis.py --target game 2A81 2AC0 to see past a relocated value).
8. _DATA found so far: main.c 00A8-01F6 (OSI_FILE's data follow at 01F6-0200), talk.c 0A06-0A36, disk.c 2A64-2B34, MOUSE 2B34-2B42, LOW 2B42-2BDA.
